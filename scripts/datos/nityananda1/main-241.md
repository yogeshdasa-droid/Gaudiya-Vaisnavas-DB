## The twelve gopālas

The **dvādaśa gopāla** are twelve associates of Śrī Nityānanda Prabhu who in Kṛṣṇa-līlā were cowherd friends of Kṛṣṇa and Balarāma. The lists vary from book to book (*Ananta-saṁhitā*, *Gaura-gaṇoddeśa-dīpikā*, *Caitanya-saṅgīta*, *Pāṭa-paryaṭana*, *Vaiṣṇavācāra-darpaṇa*; see Amulyadhana Rāyabhaṭṭa, *Dvādaśa Gopāla*, pp. 3–13). According to the *Gaura-gaṇoddeśa-dīpikā* (Gaura-līlā — Kṛṣṇa-līlā):

1. [[Abhirāma Ṭhākura#ficha-6|Abhirāma Ṭhākura]] (Rāmadāsa) — **Śrīdāmā**. Khānākula Kṛṣṇanagara.
2. [[Uddhāraṇa Datta Ṭhākura#ficha-1567|Uddhāraṇa Datta Ṭhākura]] — **Subāhu**. Saptagrāma, Uddhāraṇapura.
3. [[Kamalākara Pippalāi#ficha-657|Kamalākara Pippalāi]] — **Mahābala**. Māheśa.
4. [[Kālīya Kṛṣṇa Dāsa Ṭhākura#ficha-639|Kāla Kṛṣṇadāsa]] — **Lavaṅga**.
5. [[Gaurīdāsa Paṇḍita#ficha-325|Gaurīdāsa Paṇḍita]] — **Subala**. Ambikā-Kālnā.
6. [[Dhanañjaya Paṇḍita#ficha-1814|Dhanañjaya Paṇḍita]] — **Vasudāma**. Śītala-grāma.
7. [[Parameśvara Dāsa Ṭhākura#ficha-1080|Parameśvarī dāsa]] — **Arjuna**.
8. [[Nāgara Puruṣottama]] — **Dāma**.
9. [[Puruṣottama Dāsa#ficha-1129|Puruṣottama dāsa]] — **Stoka-kṛṣṇa**.
10. [[Maheśa Paṇḍita#ficha-894|Maheśa Paṇḍita]] — **Mahābāhu**.
11. [[Kholāvecā Śrīdhara#ficha-1833|Śrīdhara (Kholāvecā)]] — **Madhumaṅgala**.
12. [[Sundarānanda Ṭhākura#ficha-1496|Sundarānanda Ṭhākura]] — **Sudāmā**. Haldā Maheśpur.

Some count [[Halayudha Ṭhākura#ficha-442|Halāyudha Ṭhākura]] (Prabala) in place of Nāgara Puruṣottama.

## The twelve upagopālas

According to the *Vaiṣṇavācāra-darpaṇa* (p. 334):

| In Kṛṣṇa-līlā | In Gaura-līlā | Śrīpāṭa |
|---|---|---|
| Subala | Halāyudha Ṭhākura | Rāmacandrapura (Navadvīpa) |
| Varūthapa | Rudrarāma Paṇḍita | Vallabhapura |
| Gandharva | Mukundānanda | Navadvīpa |
| Kiṅkiṇi | Kāśīśvara | Vallabhapura |
| Aṁśumān | Ojhā Vanamālī | Kulyāpāḍā |
| Bhadrasena | Śrīmanta Ṭhākura | Rukuṇapura |
| Vasanta | Murāri Māiti | Vaṁśīṭoṭā |
| Ujjvala | Gaṅgādāsa | Naihāṭī |
| Kokila | Gopāla Ṭhākura | Gaurāṅgapura |
| Vilāsī | Śivāi | Belun |
| Puṇḍarīka | Nandāi | Śāligrāma |
| Kalaviṅka | Viṣṇāi | Jhāmaṭapura |
